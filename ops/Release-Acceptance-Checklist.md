# 潮安发布验收表（对齐 PRD v2.0 §7）

> 用途：上线前逐项勾选，与 [prototype-html/PRD-开发版.md](../prototype-html/PRD-开发版.md) 一致。

## 7.1 功能验收

| # | 项 | 验收方式 | 通过 |
|---|----|----------|------|
| F1 | 登录 → AI 对话记录 → 趋势报告 → 就医沟通清单 | 真机/模拟器走通主链路 | ☐ |
| F2 | 呼吸练习：进入详情并完成至少一轮（开始/暂停/恢复/倒计时递减正常） | 手动 + 可选 UI 自动化 | ☐ |
| F3 | 社区：官方科普流与用户经验流均可浏览（数据来自运营包或远端 API，非仅硬编码 mock） | 切换分段、进入详情 | ☐ |
| F4 | 对话结构化提取写入日记并参与报告分析 | 发送含症状文本后查看报告 | ☐ |
| F5 | 高风险输入触发安全策略与审计（不输出不当医疗建议） | 使用安全回归用例集 | ☐ |

## 7.2 质量验收

| # | 项 | 验收方式 | 通过 |
|---|----|----------|------|
| Q1 | CI：`build` / `unit-tests` / `ui-smoke` / `medical-eval` 全绿 | GitHub Actions | ☐ |
| Q2 | 无 P0 阻塞缺陷 | Issue/回归记录 | ☐ |
| Q3 | 同步失败率、远端失败率在约定阈值内（若有线上面板） | 监控截图/报表 | ☐ |

## 7.3 合规验收

| # | 项 | 验收方式 | 通过 |
|---|----|----------|------|
| C1 | 隐私政策、用户协议、医疗免责声明入口可达 | 设置与导航 | ☐ |
| C2 | 应用内文案无「诊断/确诊/替代医生」等误导表述 | 文案抽查 | ☐ |
| C3 | 首次使用对隐私与免责声明的告知策略已执行（若产品要求） | Onboarding/弹窗 | ☐ |
