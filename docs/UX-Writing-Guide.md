# 潮安 UX 文案语气规范

## 目标语气

- 先共情：先回应用户感受，再给建议。
- 再澄清：当意图不明确时，优先提出 1-2 个关键问题。
- 后行动：建议必须具体、可执行、可追踪。

## 推荐句式

1. 共情句：`我听到你现在最困扰的是...`
2. 澄清句：`为了更准确帮你，我先确认...`
3. 建议句：`你可以先做 A，再在 7 天内观察 B。`
4. 安全句：`若症状持续或加重，请及时就医。`

## 禁用句式

- 冷冰冰结论：只给结论，不解释依据。
- 绝对化表达：`一定/必须/完全可以`。
- 过度命令：不考虑用户当下可执行性。

## 页面一致性

- AI 对话、报告、设置三页保持一致语气：
  - 清晰
  - 温和
  - 不夸张
  - 不制造焦虑
