# 潮安 UIUX 设计版 PRD（v1.0）

> 面向对象：UI / UX 设计师  
> 基础来源：产品 PRD v2.0（生活方式与科普支持定位）  
> 使用方式：本文件用于设计产出与评审，不替代技术实现文档。

## 1. 设计目标与边界

## 1.1 设计目标

- 把更年期相关的“焦虑感”转为“可理解、可执行、可坚持”的日常体验。
- 保证三条核心路径直达：`AI对话`、`呼吸练习`、`社区科普`，并被`报告复盘`闭环。
- 提升高频路径可读性：用户进入页面 10 秒内知道“下一步做什么”。
- 在医疗敏感场景中保持“温和但明确”的安全提示。

## 1.2 产品边界（设计必须遵守）

- 不输出诊断结论，不暗示替代医生。
- 所有高风险提示必须有“建议就医/寻求专业帮助”语义。
- 社区、AI、报告文案均不使用“确诊/治愈/处方”措辞。

## 2. 用户与场景（设计视角）

- 目标用户：围绝经期/绝经期女性，常见需求为记录波动、缓解不适、理解变化、准备就医沟通。
- 典型场景：
  - 晚间睡前：情绪波动、睡眠焦虑，需要快速调节（呼吸练习）。
  - 日间突发不适：潮热、心悸、烦躁，需要即时记录并得到建议（AI对话）。
  - 非实时学习：想看可信内容或同伴经验（社区）。
  - 周期回顾：想知道“最近到底变好还是变差”（报告）。

## 3. 信息架构与导航

- 一级 Tab（固定四项）：
  - `AI对话`
  - `社区`
  - `呼吸练习`
  - `我的`
- 核心二级页：
  - 趋势报告
  - 就医沟通清单
  - 隐私政策 / 用户协议 / 医疗免责声明
  - 设置（含运行告警）

设计要求：

- Tab 样式、图标尺寸、激活态在所有页面保持一致。
- 二级页返回路径清晰，避免用户“跳进深层后迷路”。

## 4. 核心体验支柱（设计优先级）

- `AI对话（35%）`：记录与引导主入口，强调输入反馈和对话可读性。
- `呼吸练习（25%）`：当下调节工具，强调低认知负担与节奏感。
- `社区（20%）`：科普与支持，强调筛选效率与内容可信感。
- `报告（20%）`：洞察与复盘，强调“先结论后细节”。

## 5. 页面级设计要求（给设计师的具体任务）

## 5.1 AI对话页

目标：

- 让用户“开口成本最低”，并快速获得“被理解 + 可执行建议”。

布局要求：

- 聊天气泡区：主视觉中心，优先保证阅读节奏（行高、留白、左右对比）。
- 顶部轻标签：品牌陪伴感（例如“潮安AI小棉袄”），不抢内容。
- 底部输入栏固定：`+`、文本输入、语音按钮、发送按钮。
- 快捷问题胶囊：用于降低首次输入门槛。

状态要求：

- 空输入态、输入中、发送中、发送失败（可后续接入）、高风险提示态。
- 长文本与多轮会话时，滚动与新消息定位要稳定。

交互细节：

- 发送按钮在空输入时弱化。
- 语音不可用时有清晰降级提示。
- 键盘弹起时输入区域不遮挡会话内容。

## 5.2 呼吸练习页（列表 + 详情）

目标：

- 在用户不适当下，3 秒内找到可开始的练习。

列表页要求：

- 场景卡片清晰区分（潮热、夜醒、睡前、焦虑等）。
- 推荐卡展示“为什么推荐给你”（可基于近期记录）。
- 卡片信息层级：标题 > 副标题 > 时长。

详情页要求：

- 呼吸节奏可视化（吸/停/呼）直观可感知。
- 播放/暂停主按钮需强视觉确认。
- 剩余时间、阶段剩余秒数始终可见。
- 完成态需要正反馈（可轻量，不必过度游戏化）。

## 5.3 社区页（官方 + 用户）

目标：

- 让用户快速获取可信内容，同时感到“有人和我一样”。

列表页要求：

- 分段切换：官方/用户切换明显。
- 搜索框位置固定、认知负担低。
- 卡片风格统一，但官方与用户可有轻微语义区分。

发布页要求：

- 发布前展示社区规范提示（简短明确）。
- 编辑区支持标题、正文、标签，避免信息过载。

风控提示：

- 对医疗敏感内容采用“提醒式语气”，不做惊吓式设计。

## 5.4 报告与就医沟通清单

目标：

- 先给结论，再给证据，再给行动建议。

报告页要求：

- 顶部必须有“本期重点结论”卡。
- 趋势信息避免复杂图表堆叠，优先可读性。
- 建议区区分“可立即执行”和“需要观察”。

就医清单页要求：

- 一键复制/保存动作明确。
- 清单内容结构化（症状、频率、触发因素、想问医生的问题）。

## 5.5 我的与设置

目标：

- 让用户快速找到“与自己有关的复盘和合规信息”。

要求：

- 高频入口前置：趋势报告、就医清单、隐私与免责声明。
- 设置页中的开关、告警、法律入口信息层级清晰，避免同权重堆叠。

## 6. 视觉与组件规范

风格关键词：

- calm / soft / premium / reassuring

基础规范：

- 大圆角、轻阴影、半透明卡片（避免硬块纯白）。
- 主按钮样式统一；次按钮保持同一语义色阶。
- 输入框药丸形态统一，占位文案色阶一致。

一致性红线：

- 不允许不同页面出现不同 Tab 样式和图标尺度。
- 不允许高饱和突兀强调色破坏整体情绪。

## 7. 文案与语气规范（设计需联动）

- 语气：共情、克制、可执行。
- 推荐句式：先确认感受，再给建议，再给下一步选择。
- 禁用词：确诊、治愈、处方、替代医生。

## 8. 可用性与无障碍要求

- 文本对比度满足可读标准（尤其浅色背景上的次级文字）。
- 关键按钮点击热区足够（不小于 iOS 常规触控建议）。
- 动效不过载，呼吸动画与文案提示同步。
- 长文内容支持动态字体场景下不崩版。

## 9. 设计交付清单（必须项）

- 信息架构图（站点地图 + 关键流转）
- 低保真线框（四主模块 + 核心二级页）
- 高保真视觉稿（含深浅层级和空态）
- 交互说明（关键状态、动效、异常态）
- 组件库（按钮/输入/卡片/Tab/标签/对话气泡）
- 文案规范卡（医疗边界与语气示例）

## 10. 设计验收（UIUX 评审口径）

- 用户能在 10 秒内识别每页主任务。
- AI对话、呼吸练习、社区、报告四条路径均可直接进入并返回。
- 高风险提示语气正确，不制造诊断误导。
- 全局视觉一致性达标（按钮、Tab、卡片、输入框）。
- 空态、加载态、错误态均有明确设计。

## 11. 建议协作节奏

- 第 1 周：AI对话 + 呼吸练习（高频高价值）
- 第 2 周：社区 + 报告（内容与复盘闭环）
- 第 3 周：我的/设置 + 全局一致性 + 交付打包
