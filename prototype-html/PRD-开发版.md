# 潮安 PRD（v2.0）

> 更新日期：2026-04-26

## 一、产品定义

- 产品名称：`潮安`（MenoCalm）
- 平台：iOS（SwiftUI）
- 核心价值：围绕更年期场景，提供“AI 对话记录 + 呼吸练习调节 + 社区科普支持 + 趋势报告复盘”的日常支持闭环，帮助用户提升自我觉察与自我调节能力
- 目标用户：处于围绝经期/绝经期，需长期追踪症状与生活方式的女性用户
- 产品定位：生活方式与健康教育支持产品，不提供医疗诊断，不替代专业医疗服务

## 二、产品目标与非目标

### 2.1 目标

- 让用户在 1 分钟内完成当天记录，并获得可执行的生活方式建议
- 让用户在不适当下可快速进入呼吸练习，完成至少一轮自我调节
- 让用户通过社区科普与经验内容降低焦虑、提升对更年期变化的理解
- 让用户在 10 秒内读懂本期关键结论（报告页）
- 在医疗敏感表达下优先给出安全防护与就医建议
- 支持云同步、鉴权、灰度、回滚等上线能力

### 2.2 非目标（严格边界）

- 不输出医学诊断结论
- 不替代医生问诊
- 不承诺对任何症状进行治疗
- 不将 AI、练习或社区内容表述为医疗处方

## 三、信息架构（当前版本）

- 一级导航：
  - `AI对话`：记录、澄清与日常建议主入口
  - `社区`：科普知识与同伴经验支持
  - `呼吸练习`：情绪稳定与睡眠前调节工具
  - `我的`：报告、合规、设置、告警与运行状态
- 核心二级页面：
  - 趋势报告
  - 就医沟通清单
  - 隐私政策 / 用户协议 / 医疗免责声明
  - 设置与运行告警面板

## 四、核心能力需求（按模块）

### 4.0 模块优先级权重（用于排期取舍）

- `AI对话（记录与引导）`：35%
- `呼吸练习（调节与稳定）`：25%
- `社区（科普与支持）`：20%
- `报告（洞察与复盘）`：20%

排期原则：

- 若资源有限，优先保证 AI 对话的记录完整性、安全边界与可用性
- 呼吸练习与社区并行推进，优先保障“当下可执行调节”和“可信科普可达”
- 报告能力至少保证「本期重点结论 + 关键趋势 + 就医沟通摘要」可稳定产出
- 不以牺牲医疗边界换取短期功能数量

### 4.1 AI 对话（P0）

- 支持自然文本输入与快捷问题填充
- 支持“先澄清后建议”与“直接建议”策略切换（AB 开关）
- 多轮短会话记忆，降低重复提问
- 输出风格：共情句 + 可执行建议 + 下一步提问
- 对高风险表述进行安全拦截与就医引导

### 4.2 结构化提取与报告（P0）

- 对话自动提取：症状 / 触发因素 / 生活方式
- 支持 7/30/90 天趋势分析与相关性分析
- 报告页前置“本期重点结论”
- 支持就医沟通清单生成与导出（复制/保存/图片）

### 4.3 医疗可靠性与安全（P0）

- 规则化医疗安全分级（低/中/高风险）
- 对话审计日志（含手机号脱敏）
- RAG 引用输出与知识库版本标记
- 医疗评测门禁：召回率、误报率、引用覆盖率

### 4.4 数据与后端能力（P0）

- 手机号登录、token 生命周期管理（登录/刷新/失效回收）
- 远端 Journal API 联调（含 401 刷新重试，400/401/403/404/409/429/5xx 映射）
- 本地优先 + 异步上云
- `SyncQueue` 任务状态机（pending/running/retried/failed/succeeded）与历史轨迹
- 冲突解决：优先 `revision`，回退时间戳 + 字段级合并

### 4.5 运行与发布能力（P0）

- 环境隔离：dev / staging / prod
- 四道 CI 门禁：`build` / `unit-tests` / `ui-smoke` / `medical-eval`
- 监控与告警：崩溃、远端失败率、同步失败率、关键异常
- 灰度发布与回滚演练能力（有演练记录）

## 五、体验与设计规范（当前口径）

- 风格：soft premium wellness，克制、柔和、可读
- 颜色：沿用既有主色体系，不引入高饱和突兀主操作色
- 一致性：
  - 底部 Tab 文案、顺序、图标、反馈一致
  - 主按钮/次按钮/输入框样式统一
  - 风险提示语气克制但明确
- 医疗文案：
  - 禁止“诊断型措辞”
  - 涉及严重风险必须有明确就医提示

## 六、数据与关键实体（当前实现）

- 会话与鉴权：`AuthSession`、`AuthTokenManager`
- 日记与抽取：`JournalEntry`、`ExtractedData`
- 远端同步：`RemoteJournalRepository`、`SyncQueue`
- 医疗能力：`MedicalSafetyGuard`、`RAGService`、`ConversationAuditor`
- 报告分析：`ConversationInsight`、`ReportSnapshot`、`CorrelationAnalyzer`
- 可靠性：`RolloutMonitor`、`OperationalAlertingCenter`

## 七、上线验收标准（Go/No-Go）

### 7.1 功能验收

- 用户可完成登录 -> 对话记录 -> 报告查看 -> 就医清单路径
- 用户可进入呼吸练习并完成至少一轮引导流程（开始/暂停/结束状态正常）
- 用户可在社区完成科普内容浏览与经验内容浏览两类核心路径
- 对话提取结果可写入并参与报告分析
- 高风险输入可触发安全策略与审计记录

### 7.2 质量验收

- CI 四道门禁持续全绿
- 核心路径无 P0 blocker
- 同步失败率与远端失败率在阈值内稳定

### 7.3 合规验收

- 隐私政策、用户协议、医疗免责声明入口可达且文案一致
- 关键页面无医疗误导表达
